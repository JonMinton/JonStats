# JonStats

A statistics course website by Jon Minton: GLMs, likelihood and simulation, and supplementary courses on causal inference, time series, survival analysis, hacker stats and p-values. Built with [Quarto](https://quarto.org); live at [stats.jonminton.net](https://stats.jonminton.net). Interactive companion: [stats-board.jonminton.net](https://stats-board.jonminton.net) ([repo](https://github.com/JonMinton/glm-dashboard-explainer)).
